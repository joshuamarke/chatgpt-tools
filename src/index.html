使用说明

部分主题皮肤只适配深色或者浅色模式，需要重启客户端。更换皮肤不能改变功能只能改变外观。

基本操作

  • 换肤：将鼠标移到卡片预览上，点「使用皮肤」或「重新应用」
  • 导入：主区域点「导入皮肤」，选择 .cgskin / .zip 皮肤包
  • 导出：将鼠标移到卡片预览上，点「导出」分享给别人
  • 恢复默认：顶部点「恢复默认」，还原官方界面并自动重开 ChatGPT

导入安全

皮肤包可含脚本，会在 ChatGPT 界面执行。导入时会弹出警告并显示脚本哈希；请只导入可信来源。

小提示

  • 需已安装 ChatGPT / Codex 桌面版
  • 若提示未安装，可在左侧点「选择客户端」手动选择 exe
  • Microsoft Store 版也会自动识别
  • 不修改官方安装包，可随时还原
  • 同时只建议启用一套皮肤
  • DevTools：「自定义皮肤」弹窗内的调试工具，简化版类 Chrome 开发者工具
