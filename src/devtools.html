关于 Skin DevTools

独立调试窗口：主窗口「自定义皮肤」弹窗顶部「DevTools」按钮打开（不占用 F12）。

  • Elements：在真实宿主窗口点选（CDP Overlay），左侧层级 DOM 树，右侧 Styles / Computed；中间可拖动调整宽度
  • 面包屑：点击祖先节点可在 DOM 树中定位并选中
  • 关闭窗口：自动断开 inspect CDP（结束点选、释放 Overlay/DOM 会话与轮询）
  • Host / Runtime / Skins：生命周期与换肤会话诊断
  • Tauri 自带 F12 只能审查本工具窗口，宿主审查必须走 CDP
